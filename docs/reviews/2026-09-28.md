# Repository review - 2026-09-28

Scope: tracked source and configuration at afc1985, plus the user's local
test-project migration to xunit.v3 4.0.0. This is a baseline review, not a
claim that the planned MVP already exists.

## Findings

1. P1 - Test runner migration is incomplete (both test csproj files).
   After restore, the current CI-style dotnet test fails: MTP 2.3.3 rejects
   VSTest invocation on .NET 10. Build success alone does not validate tests.
   Fixed with xunit.v3.mtp-off 4.0.0 and explicit executable test projects,
   preserving xUnit v3 and the existing VSTest pipeline. Existing health
   test now propagates the xUnit cancellation token.
2. P2 - API request sample still calls /weatherforecast (Api/CyclingRoutes.Api.http).
   That endpoint was removed, so the supplied sample returns 404.
   Updated to /health, text/plain and the local HTTPS launch profile.
3. P3 - Docker restore cache does not cover referenced projects (Api/Dockerfile).
   Only the API csproj was copied before restore; its project references were
   absent from that layer. The later implicit build restore can compensate,
   but the dependency layer is incomplete and restores repeat. Added all four
   referenced csproj files before restore and made subsequent steps no-restore.

## Scope and gaps

- The only existing test was /health. The new domain stage adds unit coverage.

- Health currently checks process responsiveness only, not external dependencies.
- Container build and HTTP smoke test pass after Docker Desktop was started.
